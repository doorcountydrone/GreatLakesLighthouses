Help & Instructions

Quick start

1. On your phone, join the map's setup Wi-Fi: name GreatLakes-Setup, password door1234.

2. Pico settings: enter your home (or hotel) Wi-Fi name and password — not the setup password — then tap Save & Reboot. Wait for the map to restart and join your network.

3. Lighthouses: the Door County lights are already there. Change the list if you want, then tap Save list.

Done. The lights blink like the real lighthouses.

What is this map?

Great Lakes Lighthouses is a wall map of lights. Each light matches a real lighthouse: white or red, steady or flashing, the same rhythm the lighthouse uses on the water.

You do not need to program anything. Use the Android app, or this page in a phone or computer browser. Both let you pick which lights are on the strip, and set Wi-Fi, brightness, and sleep.

Getting started

1. Connect to the map's Wi-Fi

The first time you plug the map in, it makes its own Wi-Fi named GreatLakes-Setup. Password: door1234. Join that network on your phone. Turn off mobile data if your phone keeps leaving Wi-Fi.

Address: 192.168.4.1

2. Give the map your home Wi-Fi (Pico settings)

Type your home or hotel Wi-Fi name and password. That is so the map can reach the internet — not so your phone can join GreatLakes-Setup.

Tap Save & Reboot. After it restarts, put your phone back on home Wi-Fi. The map's address is now its home-network address, for example http://192.168.1.22. You can find that in your router's device list.

3. Set your lights (Lighthouses)

A finished Door County map already has Kewaunee through Rock Island. Reload shows what is on the map. Save list writes your list. List order is the order of the lights on the strip, south to north.

Lighthouses tab

Your light list

Reload loads the list that is already on the map.

Save list sends your list to the map. Do this after you add, skip, reorder, or remove lights.

Use / skip: skip leaves that light dark but keeps its place on the strip.

Drag the handle (app) or Up / Down (browser) to move a light. First in the list is the first light on the strip (usually the southernmost).

Add from catalog lets you browse by shore (Chicago, Wisconsin, Green Bay, Michigan, Straits) or search by name. Color, flash, and nearest weather station are already filled in. Tap one to add it.

Add custom is for a name, a flash pattern, and an optional nearby weather station (for example KSUE).

Restore defaults puts back Kewaunee through Rock Island. Then tap Save list.

Finished map vs building your own

A finished Door County map already has the lights set. You do not need to add or remove any.

Adding, skipping, or reordering is for a custom map. Put lights in the same order as the strip on the board. No programming — just this page or the app.

Pico settings tab

Wi-Fi, brightness, and sleep

Home Wi-Fi name and password are for your router, not GreatLakes-Setup. Leave password blank to keep the one already saved.

Extra display is LED strip only, OLED (GPIO 16–19), or LED matrix (GPIO 1). The lighthouse strip is always on. Save & Reboot after you change this.

LED matrix scroll is Weather only (default) or All lights. Weather only lists lights that currently have rain, fog, snow, lightning, or similar. If none do, it scrolls GREAT LAKES LIGHTHOUSES about every 15 seconds. Matrix scroll speed is 1 (slow) to 10 (fast). The IP scrolls once at startup.

Max brightness is how bright the lights get in a bright room (1 to 30). Min brightness should stay at 2 so red and white still look right when the room is dark.

Optional OLED (SSD1306): GPIO 16 data (SDA), 17 clock (SCL), 18 for 3.3 V, 19 for ground. Copy ssd1306.py onto the Pico. The screen cycles IP, LDR brightness, and METAR.

Optional LED matrix (8x32 WS2812): data on GPIO 1, 5 V and common ground — not from pin 18. Copy led_matrix.py onto the Pico. Light names use flight-category color; weather codes use MetarMap colors (rain cyan, snow/fog white, lightning yellow, wind yellow, storms red).

Refresh seconds is how often the map checks online (30 to 3600). 300 is every 5 minutes.

Sleep turns the lights off and on each night. Set the time offset first (Central: -6 in winter, -5 in daylight saving. Eastern: -5 / -4).

Weekend / long off is an extra off stretch, for example Friday evening to Monday morning. It works together with nightly sleep.

On this page, Save & Reboot saves settings and restarts the map. That is normal.

Install firmware update downloads a newer map program from the internet and restarts. The map must be on home Wi-Fi. Your light list and Wi-Fi stay. Until you tap Install, the map keeps running as it is.

Firmware updates

When a newer version is ready

After the map joins home Wi-Fi, it checks online for a newer version. It does not install by itself.

If an update is waiting, the lights flash amber for a couple of seconds after startup. On Pico settings, tap Install firmware update (app or this page). You can also tap the setup button quickly while the map is running. A long hold at power-on still opens GreatLakes-Setup.

The map goes dark for a bit, then comes back. Wait about 30 seconds, then Fetch to confirm.

Using the app

The Android app has three tabs along the bottom: Lights, Settings, and Help.

On GreatLakes-Setup, set Pico address to 192.168.4.1. After the map is on home Wi-Fi, set it to the map's home-network address (for example http://192.168.1.22).

Lights tab: Fetch from Pico and Save to Pico. Settings tab: Fetch, Save, Save & reboot, or Install firmware update.

Troubleshooting

App / phone / browser

Can't connect: join GreatLakes-Setup (password door1234) and use address 192.168.4.1. Turn off mobile data so the phone stays on that Wi-Fi.

Fetch or Save failed: your phone must be on the same Wi-Fi as the map. After setup, both must be on home Wi-Fi, and the address must be the map's home-network address.

Type http:// in front of the address if the page will not open.

Phone hotspot: putting the map on a hotspot that uses cellular often fails. Use home or hotel Wi-Fi when you can.

The lights

A light stays dark: check that it is set to Use, not skipped. Check sleep and weekend off times.

Sleep never turns the lights off: the map needs home Wi-Fi so it can set the clock, and the time offset must match your local time.

Catalog search is empty: use Restore defaults or Add custom. On a finished map the catalog is already there.
